### 🌟 CutPilot Pro 数字化场记与智能粗剪

CutPilot Pro 是一款面向剪辑师与内容创作者的 AI 数字化场记与粗剪工具。

#### ✨ 核心特性
- 🎙️ **多引擎语音识别**：支持阿里 DashScope (SenseVoice/Paraformer) 与火山引擎大模型语音识别。
- ⚡ **本地推理支持**：支持本地 SenseVoice-Small 快速识别，无网络也能高效工作。
- 🎬 **智能场记与粗剪**：精准断句、词级时间戳对齐，轻松联动达芬奇（DaVinci Resolve）时间线。
- 🖥️ **跨平台桌面体验**：原生风格界面，流畅的多媒体预览与智能校对。

#### 🍎 系统要求与安装说明
- **支持系统**：macOS 11.0 (Big Sur) 及更高版本（原生适配 Apple Silicon M 系列芯片）。

- 🌟 CutPilot Pro: Digital Logging & Smart Rough-Cut Assistant
CutPilot Pro is an AI-powered assistant built for video editors and creators, streamlining digital script logging and rough-cut assembly.

✨ Key Features
🎙️ Multi-Engine ASR: Integrated with Alibaba Cloud DashScope (SenseVoice/Paraformer) and ByteDance Volcano Engine speech-to-text models.

⚡ On-Device Inference: Runs SenseVoice-Small locally for fast, reliable transcription even without an internet connection.

🎬 Smart Logging & Rough Cuts: Delivers precise sentence segmentation with word-level timestamps, syncing seamlessly into DaVinci Resolve timelines.

🖥️ Desktop Experience: Features a native-feel UI with fluid media playback and intuitive transcript proofing.

🍎 System Requirements & Installation
Supported OS: macOS 11.0 (Big Sur) or later (fully native on Apple Silicon M-series chips).
